# Feature detection: a foundation of untargeted metabolomics

- Converts raw LC–MS signals into quantifiable features.
- Summarizes each feature by m/z, retention time, and peak area.
- MS-DIAL (2015) remains widely used.
- New tools continue to emerge: IDSL.IPA, asari and MassCube.
